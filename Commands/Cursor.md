# Cursor 단축키

**기본**
- 명령 팔레트: `Ctrl+Shift+P` / `Cmd+Shift+P`
- 빠른 파일 열기: `Ctrl+P` / `Cmd+P`
- 탐색기 토글: `Ctrl+B` / `Cmd+B`
- 터미널 열기: `Ctrl+\`` / `Cmd+\``
- 전체 검색: `Ctrl+Shift+F` / `Cmd+Shift+F`

**AI 기능**
- 인라인 코드 수정: `Ctrl+K` / `Cmd+K`
- AI 채팅 열기: `Ctrl+L` / `Cmd+L`
- 에이전트 모드: `Ctrl+I` / `Cmd+I`
- 선택 코드를 채팅 컨텍스트로: 코드 선택 후 `Ctrl+L`
- 자동완성 수락: `Tab`
- 자동완성 거부: `Escape`

**편집**
- 한 줄 복사 (아래): `Shift+Alt+↓`
- 한 줄 이동: `Alt+↑/↓`
- 한 줄 삭제: `Ctrl+Shift+K`
- 주석 토글: `Ctrl+/`
- 블록 주석: `Shift+Alt+A`
- 포맷: `Shift+Alt+F`
- 선언부로 이동: `F12`
- 이름 바꾸기: `F2`

**멀티커서**
- 여러 줄 선택 후 멀티커서: `Ctrl+Shift+L`
- 수동 멀티커서 추가: `Alt+Click`
