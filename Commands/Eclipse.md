# Eclipse 단축키

**실행**
- 이전 실행 파일 실행: `Ctrl+F11`
- 디버그 실행: `F11`
- 현재 파일 실행: `Alt+Shift+X` → `J`

**편집**
- 자동 완성: `Ctrl+Space`
- 빠른 수정 제안: `Ctrl+1`
- 임포트 정리: `Ctrl+Shift+O`
- 자동 포맷: `Ctrl+Shift+F`
- 한 줄 삭제: `Ctrl+D`
- 한 줄 복사: `Ctrl+Alt+↓`
- 주석 토글: `Ctrl+/`
- 블록 주석: `Ctrl+Shift+/`

**탐색**
- 빠른 파일 열기: `Ctrl+Shift+R`
- 타입 검색: `Ctrl+Shift+T`
- 선언부로 이동: `F3`
- 참조 찾기: `Ctrl+Shift+G`
- 다음 오류로 이동: `Ctrl+.`

**리팩터링**
- 이름 바꾸기: `Alt+Shift+R`
- 메서드 추출: `Alt+Shift+M`
- 변수 추출: `Alt+Shift+L`

**뷰**
- Package Explorer 포커스: `Ctrl+Shift+Q`
- 콘솔 보기: `Alt+Shift+Q` → `C`
- 에디터 최대화: `Ctrl+M`
