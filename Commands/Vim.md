# Vim 명령어

**모드 전환**
- Normal 모드로: `Esc`
- Insert 모드로: `i` (커서 앞) / `a` (커서 뒤) / `o` (아래 새 줄)
- Visual 모드로: `v` (문자) / `V` (줄) / `Ctrl+V` (블록)
- Command 모드로: `:`

**이동 (Normal)**
- 단어 앞으로: `w` / 단어 뒤로: `b`
- 줄 처음: `0` / 첫 비공백: `^` / 줄 끝: `$`
- 파일 맨 위: `gg` / 맨 아래: `G`
- 특정 줄로: `:42` (42번 줄)

**편집**
- 한 줄 삭제: `dd`
- 단어 삭제: `dw`
- 한 줄 복사: `yy`
- 붙여넣기: `p` (아래) / `P` (위)
- 실행 취소: `u`
- 재실행: `Ctrl+R`
- 줄 번호 표시: `:set number`

**검색 / 치환**
```
/검색어          앞으로 검색
?검색어          뒤로 검색
n               다음 결과
N               이전 결과
:%s/old/new/g   파일 전체 치환
:s/old/new/g    현재 줄 치환
```

**설정**
```
:set number         줄 번호 표시
:set shiftwidth=4   들여쓰기 폭 4칸
:set cindent        C 스타일 자동 들여쓰기
:set tabstop=4      탭 크기 4
:set expandtab      탭을 스페이스로 변환
:syntax on          문법 강조
```

**파일 / 저장**
```
:w          저장
:q          종료 (변경 없을 때)
:q!         강제 종료 (변경 버림)
:wq         저장 후 종료
:e <파일>   다른 파일 열기
```

**분할 화면**
```
:split <파일>   수평 분할
:vsplit <파일>  수직 분할
Ctrl+W+W        다음 창으로 포커스 이동
:close          현재 창 닫기
```
